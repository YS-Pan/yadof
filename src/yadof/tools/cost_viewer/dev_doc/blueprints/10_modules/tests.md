# Module Blueprint: Tests

Root pytest coverage verifies row adaptation, issue isolation, objective-name
fallbacks, average-cost semantics, Pareto/generation/HV calculations, plot style,
shaded HV rendering with thin translucent boundary polylines, compact HV legend text, staggered generation labels,
compatibility imports, CLI output/progress, image output, documentation links,
and wheel/sdist inclusion. Tests should target the owning
module while retaining a small compatibility-facade contract.
