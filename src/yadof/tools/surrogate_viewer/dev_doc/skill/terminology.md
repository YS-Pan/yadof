# Terminology Contract

## Purpose And Reading

`../terminology.md` defines viewer-specific words whose boundaries are not obvious
from ordinary software usage. Read it in full during the first context pass.

Use the glossary to distinguish checkpoint generation from optimization
generation, source rawData from predictions, and complete audit aggregates from
partial runtime state.

## Maintenance Contract

Update `../terminology.md` when a change introduces a non-obvious concept, changes
the meaning of an existing term, or exposes a recurring ambiguity. Do not add
ordinary Python, Tkinter, Matplotlib, or machine-learning vocabulary unless this
project gives it a special boundary.
