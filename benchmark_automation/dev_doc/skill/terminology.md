# Terminology Contract

## Purpose and reading

`../terminology.md` defines benchmark words whose meaning differs from ordinary
software usage or encodes data ownership. Read it in full during the first context
pass.

## Maintenance

Add or revise a term when a change introduces a non-obvious identity, evidence,
state, progress, ETA, or interpretation concept. Do not add ordinary vocabulary.
Definitions describe current meaning and identify whether data is immutable input,
mutable latest state, derived evidence, or display-only output.
