# Administrator documentation

`admin_doc/` contains documentation for administrators who provision and maintain
the software and machines on which yadof tasks run. Executable administrator tools
remain in their sibling directories under `admin_tool/`.

## Topics

- [HTCondor](htcondor/README.md): deployment policy, Windows pool operations,
  troubleshooting, investigations, and historical evidence.
- [PyChrono](pychrono/README.md): pinned shared-runtime installation,
  configuration, validation, ACL, and recovery procedures.

The documentation and tools are source-checkout administrator resources. They are
not part of yadof's installed user command surface.
