# PyChrono runtime tools

This directory contains the executable installer, validation script, and mechanics
probe for the shared PyChrono runtime. Follow the canonical administrator procedure
in [the PyChrono administrator documentation](../admin_doc/pychrono/README.md)
before running them.

The installation procedure requires a separately verified official installer and
an explicit UAC-elevated run. Do not infer installation or recovery steps from the
scripts alone.
