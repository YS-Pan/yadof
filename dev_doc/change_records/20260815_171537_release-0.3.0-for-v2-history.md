# 2026-08-15 17:15 - Release 0.3.0 For V2 History

## Context

- Loss-tolerant recording replaced the mutable aggregate `indMeta.jsonl` and
  global `rawData.npz` history with immutable v2 ZIP segments.
- The new reader deliberately ignores legacy history and performs no automatic
  migration, so the `0.2.0` package version no longer communicated the persistence
  compatibility boundary clearly.

## Change

- Bumped the single authoritative yadof version from `0.2.0` to `0.3.0`.
- Updated package/user/developer documentation and the installed-package version
  assertion to identify `0.3.0` as the v2 history line.

## Rationale

- A new package version makes the intentional history incompatibility visible to
  users and keeps wheel metadata, CLI output, workspace provenance, tests, and
  documentation aligned.

## Impact

- Newly built wheels are named `yadof-0.3.0-py3-none-any.whl` and both version CLI
  forms report `0.3.0`.
- Workspace/rawData schema numbers remain unchanged because the incompatible
  boundary is recorded-history persistence, not the individual rawData NPZ format.
- Legacy aggregate history remains untouched and absent from v2 queries.
