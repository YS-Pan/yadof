# 2026-08-26 09:50 - Release 0.4.1 And Flatten Benchmark Output

## Context

- The package needed a public patch release from 0.4.0 to 0.4.1.
- Benchmark runs launched by agents had accumulated redundant
  `temp/benchmark/<task-id>/<run-id>` directory layers. The requested layout puts
  each immutable run ID directly below the checkout's ignored `temp/` root.
- Small structural and pilot runs could be mistaken for evidence suitable for
  surrogate/optimizer performance tuning.

## Change

- Updated the single runtime version source, current-version acceptance assertion,
  installation examples, and current package documentation to 0.4.1.
- Changed `benchmark.toml`'s configured run root to `../temp`, added a focused
  repository-config assertion, and updated agent, user, architecture, blueprint,
  and terminology documentation to describe `temp/<run-id>/` as the default
  layout without a benchmark/task container layer.
- Made the benchmark documentation prohibit few-generation or
  dozens-of-individual runs for surrogate/optimizer performance evaluation and
  result-driven tuning. That work must use the complete unfiltered `performance`
  matrix, currently 2,000 attempted real evaluations per measured cell and 36,000
  across 18 cells.
- Removed incidental 0.4.0 wording from current benchmark metric-gap messages while
  retaining genuine historical 0.4.0 baseline and verification provenance.

## Rationale

- A single output-root setting preserves the runner's existing immutable run-ID
  boundary while eliminating directories that add no identity or recovery value.
- Structural and pilot suites have too little search depth and population evidence
  to support algorithm-performance conclusions or tuning decisions.
- Historical benchmark identities must continue to describe the package version
  that actually produced them; only active current-version contracts were bumped.

## Impact

- Built `dist/yadof-0.4.1-py3-none-any.whl`, force-reinstalled it into the sibling
  `.venv`, and verified version 0.4.1 imports from
  `.venv/Lib/site-packages/yadof`.
- The installed-package suite passed 254 tests, and the benchmark automation suite
  passed 48 tests, both with fresh external pytest base directories and the cache
  provider disabled.
- Existing generated runs and frozen benchmark inputs were not moved, rewritten,
  or deleted.

## Follow-Up

- Future commands that explicitly override `--runs-dir` must continue to reuse the
  same resolved root for inspect, resume, collect, and report.
